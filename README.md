# ACPCC Git training

Training material for a one-hour introduction to Git and GitHub for analysts who work in R and SQL.

> **All data in this repository is synthetic.** It is generated by `data-raw/make-synthetic.R` and does not represent real screening results.

The repository has three parts:

- **Slides** (`slides/`): Git foundations for analysts, rendered to a Beamer PDF.
- **Report site**: a Quarto recreation of the [Victorian Cancer Screening Statistical Report](https://report.acpcc.org.au/), built from synthetic data.
- **Exercises** (`exercises/`): hands-on steps for RStudio, Positron and the command line.

GitHub Actions renders everything on every pull request and publishes the site to GitHub Pages when `main` changes.

## Getting started

1. Clone the repository (see Exercise 0 for RStudio and Positron steps).
2. Open `acpcc_git_training.Rproj` in RStudio, or the folder in Positron.
3. Restore packages: `renv::restore()`
4. Build the database: `source("data-raw/make-synthetic.R")`
5. Render: run `quarto render` in the terminal.
